# LynaOS Developer Builds

Repositorio oficial de las builds de desarrollo de LynaOS.

Aquí se almacenan versiones de desarrollo, pruebas y
características experimentales de LynaOS antes de su
integración en las versiones estables.

## Sobre el proyecto

LynaOS es un sistema operativo experimental basado en
Python, Bash y herramientas de Linux.

Este repositorio contiene builds destinadas al desarrollo
y pruebas.

Las builds de este repositorio pueden contener errores,
cambios experimentales o características incompletas.

## Repositorio principal

El código de las versiones estables de LynaOS se encuentra
en el repositorio principal:

https://github.com/lyna-kit/LynaOS
